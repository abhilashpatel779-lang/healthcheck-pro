# HealthCheck Pro

HealthCheck Pro is a Java-based website monitoring system.

## Features

- Checks websites as UP or DOWN
- Measures website response time
- Stores monitoring results
- Generates monitoring reports
- Uses GitHub for version control
- Uses GitHub Actions for automation

## How to Run

Compile:

javac HealthCheck.java

Run:

java HealthCheck

## DevOps Pipeline

Developer → GitHub → GitHub Actions → Build/Test → Health Check → Report
